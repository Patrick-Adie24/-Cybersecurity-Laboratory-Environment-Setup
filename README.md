# -Cybersecurity-Laboratory-Environment-Setup
Building an Isolated Virtual Laboratory for Penetration Testing and Ethical Hacking Practice
## 📌 Project Overview
This project documents the initial setup and configuration of a cybersecurity laboratory environment designed for practical learning and experimentation. The primary purpose of the laboratory is to provide a safe and controlled environment in which cybersecurity, computer networking, and penetration-testing concepts can be studied and practised without affecting production systems or real-world networks.

The initial stage of the laboratory setup involves installing the necessary software and preparing the virtualization environment. This includes downloading and installing a suitable file-compression utility for managing compressed files and preparing Oracle VirtualBox as the virtualization platform.
Oracle VirtualBox will be used to create and manage virtual machines within the laboratory. These virtual machines can provide isolated environments for conducting cybersecurity exercises, network configuration, vulnerability assessment, security testing, and penetration-testing activities.

The laboratory is intended to support practical cybersecurity training by allowing different operating systems and security tools to be installed and tested in an isolated environment. This approach makes it possible to experiment with cybersecurity techniques while reducing the risk of disrupting the host computer or other systems on the network.
The initial setup therefore establishes the foundation for subsequent laboratory activities, including virtual machine deployment, network configuration, security-tool installation, vulnerability testing, and controlled penetration-testing exercises.
## 🎯 Objectives

The main objectives of this lab are to:

- Prepare the computer for cybersecurity laboratory activities.
- Download and install the required supporting software.
- Set up Oracle VirtualBox for virtual machine deployment.
- Prepare the environment for future Kali Linux and cybersecurity labs.
- Document each stage of the laboratory setup.
